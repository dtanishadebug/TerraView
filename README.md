
# TerraView

TerraView is an image-discovery app where users will be able to search for images by topic and explore visual inspiration.

I chose a forest-green and warm-cream palette to create a calm, nature-inspired identity. I added category chips to suggest popular searches and help users discover ideas quickly. The responsive CSS Grid layout will allow image cards to fit different screen sizes.

## Technologies
- HTML
- CSS
- JavaScript
